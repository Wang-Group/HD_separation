# Weighted descriptor maps

Run `python plot_weighted_trio_letter.py`. The three columns show work function/H adsorption free energy, work function/electronegativity, and H adsorption free energy/electronegativity. Four rows show precursor/global, ICP/global, precursor/local, ICP/local.

All panels use the same complete-data cohort. Precursor weights are volume fractions under the equal-stock-concentration convention; ICP weights are metal molar fractions. Local bounds cover pooled BO ranges with 5.5% padding. Backgrounds use initial observations only; BO points are measured overlays. This script regenerates descriptive maps without fitting predictive ML models or editing Word.
