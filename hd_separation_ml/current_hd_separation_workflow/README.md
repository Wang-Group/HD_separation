# Current H/D Separation ML Workflow

This folder documents the current manuscript-facing H/D-separation machine
learning workflow. It does not duplicate the raw data; it records the scripts,
inputs, and outputs needed to reproduce the current descriptor-selection story.

## Input

The workflow starts from the corrected 561-sample no-BO feature matrix:

`../outputs/feature_selection_561_rs_from_eis_no_eis_fitting/feature_matrix_561_no_eis_fitting.csv`

The candidate descriptor list is:

`../outputs/feature_selection_561_rs_from_eis_no_eis_fitting/candidate_features.csv`

The feature matrix is generated from the corrected data extraction workflow and
uses Rs estimated directly from high-frequency EIS real impedance.

## Manuscript-Facing Logic

1. **Classification feature screening**
   - Define high-separation samples as `S_H/D >= 8`.
   - Start from all 28 candidate descriptors.
   - Evaluate all 1- to 4-feature combinations using ROC-AUC and average
     precision.
   - Use weighted occurrence in top combinations to identify the high-S
     descriptor core and descriptor families.

2. **RF/ExtraTrees-only forward addition**
   - Start from the 4-feature high-S classification core.
   - Add features greedily using mean 5-fold CV R2 from Random Forest and Extra
     Trees only.
   - XGBoost is not used for the forward-addition decision because it showed
     less stable held-out behavior in this small, correlated descriptor set.

3. **Final 10-feature model interpretation**
   - Use the 10-feature point from the RF/ExtraTrees-only forward path.
   - Train Random Forest and Extra Trees on the seed-42 stratified split.
   - Use the better held-out model, currently Random Forest, for SHAP
     interpretation.
   - Use SHAP as the main interpretability output; tree impurity feature
     importance is retained only as an internal diagnostic.

4. **BO descriptor projection**
   - Use the important descriptor families, especially electronegativity, work
     function/electronic descriptors, and H adsorption energy, to overlay BO
     samples on the initial-screening descriptor space.
   - The weighted BO projection uses raw elemental descriptors weighted by
     precursor metal-salt ratios.
