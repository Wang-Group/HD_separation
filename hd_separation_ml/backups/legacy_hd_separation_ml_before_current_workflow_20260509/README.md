# Archived Legacy H/D Separation ML Attempts

This folder caches earlier H/D-separation machine-learning notebooks, scripts,
and outputs that are no longer part of the current manuscript-facing workflow.

The active workflow is documented in:

`../../current_hd_separation_workflow/README.md`

## Archived Content

### Notebooks

Earlier seed-42 feature-selection and fixed-feature model notebooks, including
7-, 8-, 9-, and 11-feature variants.

### Outputs

Earlier grouped-feature, chemistry-constrained, seed42 backward-elimination, and
fixed-feature model output folders.

### Scripts

Exploratory scripts for earlier descriptor-family checks and older 9-feature
SHAP plots.

## Why Archived

The current analysis uses a cleaner workflow:

1. all-28 high-separation classification feature screening;
2. RF/ExtraTrees-only forward feature addition;
3. final 10-feature RF/ExtraTrees model interpretation;
4. BO overlay using key descriptor families.

The files here are retained for provenance but should not be cited as the
current manuscript workflow.
