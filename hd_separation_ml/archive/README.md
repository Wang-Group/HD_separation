# ML Archive

This folder stores auxiliary or older machine-learning files that are not part
of the active manuscript-facing no-BO model.

## Subfolders

- `fitting_variants/`
  - Older or alternate EIS fitting result tables.
- `notebooks/`
  - Auxiliary notebooks not needed to regenerate the active Figure 3 ML panel.
- `descriptor_predictions/`
  - Descriptor-prediction workbooks and intermediate prediction outputs.
- `drafts/`
  - Generated manuscript/SI draft markdown from the ML analysis.
- `system/`
  - System-generated cache files, if any.
