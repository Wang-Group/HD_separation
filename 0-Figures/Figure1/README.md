# LSV Analysis Sources

The assembled **Figure 1** is the platform schematic:
[SVG](../manuscript/Figure1.svg), [PNG](../manuscript/Figure1.png),
[PDF](../manuscript/Figure1.pdf).

This source directory contains the [LSV extraction and activity analysis](revision_figure/README.md).
Its per-curve results support repeatability analysis and the activity/separation
comparison in **[Figure 4D](../manuscript/Figure4.svg)**.

For Figure 4D, use the two-axis experimental means and SDs in the
[manuscript source tables](../manuscript/source_data/) and the
[joint repeatability analysis](../../others_revision/reproducibility_overview/README.md).
Crossing values, estimates and scan limits remain separate; BO-reference
measurements are retained for experimental repeatability, not averaged ML targets.

`revision_figure/figure1b_outputs/` is a companion comparison using screening
H/D coefficients and horizontal activity SDs. It is not the assembled Figure 4D.
Required extraction test fixtures remain with the extractor.
