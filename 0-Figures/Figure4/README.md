## Recorded BO Performance

[curated/figure4_bo_complete_112.csv](curated/figure4_bo_complete_112.csv)
contains 28 recorded experiments each for Co-Mo, Co-V, Co-Ni and Fe-Ni.
The BO objectives are not replaced by retrospective repeatability averages.

Run `pareto_polygon_enclosure_code.ipynb` with this directory as the working
directory to plot the batch-performance panels. It reads the curated CSV and
writes `eight_panels_2x4_batch1_7_lg.png`; that file is a panel source, not the
complete Figure 4. The notebook requires NumPy, pandas, Matplotlib and Shapely.

`BO.ipynb`, the BO workbooks, initial-sampling JSON files and individual
comparison TIFFs retain formulation and experimental provenance. Platform
optimization details are in [BO provenance](../../EC_tool_sys/BO_PROVENANCE.md).

## Descriptor Maps and Experimental Means

The ICP-weighted work-function, H-adsorption and electronegativity maps are
generated by [ml_revision/plot_weighted_trio_letter.py](../../ml_revision/plot_weighted_trio_letter.py).
Their [outputs](../../ml_revision/figures/weighted_descriptor_maps/)
include initial-only global maps and the four-system BO overlay.
`descriptor_joint_panel_helpers.py` is imported by that workflow and is a
required reproduction dependency.

The bottom activity/separation panel uses mean and sample SD for both axes.
Use the [plotted source tables](../manuscript/source_data/) and
[joint repeatability analysis](../../others_revision/reproducibility_overview/README.md).
These experimental summaries include same-recipe reference measurements;
the averaged ML targets exclude those BO references.

See the [manuscript panel source map](../manuscript/README.md) for the assembly.
