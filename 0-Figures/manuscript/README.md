# Manuscript Figures

`Figure1.svg`, `Figure3.svg` and `Figure4.svg` are the editable assembly masters.
The matching PNG/PDF files are the adopted exports. Layouts are assembled in SVG;
panel-analysis scripts do not automatically replace the complete compositions.

| Content | Source |

The SHAP panel uses three-repeat random-stratified validation without BO and
training-only correlation-aware selection. The projections display measured
H/D coefficients, not model-predicted response surfaces. The global maps use
232 initial samples; the BO overlay adds 84 independent samples from Co-Mo,
Co-V, Co-Ni and Fe-Ni. The initial-only maps do not contain BO observations.

## Activity/Separation Source Tables

`activity_separation_points.csv` records the plotted catalyst means and sample
SDs: `x`/`sd` are overpotential in mV, `y`/`HD_SD` are H/D coefficient values,
and `metric` distinguishes measured crossings, estimates and bounds. Blank SD
is not zero. Numerical values are retained before the 10-550 mV display clipping.
Same-recipe reference measurements are retained in the experimental summaries.
This table is not an ML target table.

`activity_separation_frontier.csv` records the ordered frontier vertices. Blank
sample labels denote literature vertices, not missing catalyst measurements.
The literature source is `../Figure1/revision_figure/figure1b_inputs/literature.csv`.

## Export

Keep Arial available and use the page bounds when exporting an edited SVG with
Inkscape. Shared superscript/subscript handling is provided by
`../figure_typography.py`. Scientific panel regeneration instructions are in
`../../ml_revision/README.md` and `../../others_revision/README.md`.

Figure numbers here identify the assembled manuscript files. Analysis data and
scripts elsewhere use content-based names, independent of document numbering.
