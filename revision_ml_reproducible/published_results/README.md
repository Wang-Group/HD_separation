# Archived Scientific Results

These files are unchanged reference outputs from the completed revision analyses.
The primary line is the 33-candidate nested workflow. The 39-candidate,
electrochemical-input, missing-reference, identity and frozen-model analyses are
supporting controls, not interchangeable headline estimates.

Start with [the latest interpretation](reviewer_ml_completion_20261014/RESULTS.md).
Raw inputs and reference model settings are elsewhere in this package; the
archived report figures are not used as training data.

Some historical reports contain machine-specific interpreter paths or commands
for the original sequence of run directories. They are preserved as provenance,
not portable instructions. Use [the package README](../README.md) and `run.py`.
